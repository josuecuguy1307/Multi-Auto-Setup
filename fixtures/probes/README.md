Recorded or hand-written outputs for the os-probes tests. `darwin/` is a real capture from a Mac (it holds no serial or name). The `windows/` files are WRITTEN FROM THE DOCUMENTED FORMAT of the Windows tools and are UNTESTED against a real Windows machine: they remain unverified. `windows-real/typed_facts.redacted.json` is the first REAL Windows capture (2026-10-30, Windows 11 amd64, through a paired node): the TYPED facts the probes returned, not the raw tool text, which the node does not send. A raw capture needs the owner to run the read-only commands on the machine himself. `linux-*` are hand-written in the real formats (Debian/Ubuntu: dpkg-query, flatpak, lspci; Fedora: rpm, lspci).
