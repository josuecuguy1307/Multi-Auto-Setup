Recorded or hand-written outputs for the os-probes tests. `darwin/` is a real capture from a Mac (it holds no serial or name). The `windows/` files are WRITTEN FROM THE DOCUMENTED FORMAT of the Windows tools and are UNTESTED against a real Windows machine: they are replaced by redacted captures from the first real Windows run. `linux-*` are hand-written in the real formats (Debian/Ubuntu: dpkg-query, flatpak, lspci; Fedora: rpm, lspci).
