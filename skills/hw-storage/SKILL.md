# Storage volumes

Lists the volumes with their file system, size, free space and whether they are internal or removable. External volumes are counted separately because a removable disk is the first sign that something was plugged in.

The duplicate system volume that macOS mounts for updates is skipped, so one disk is not counted twice. Free space changes on its own and is recorded as volatile.
