# GPU and displays

Lists the graphics processors (with core counts and the graphics API family on a Mac) and every attached display with its resolution and connection. A machine with no display is a strong hint that it is a server or a board; a machine with several is a workstation.

Names are kept; serial numbers and display identifiers are used only to tell two entries apart and are hashed, never stored.
